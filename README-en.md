# observabilidade-stack-grafana_tech-summit-2026-08
Contents of the presentation “Unified Observability with the Grafana stack: from applications to cloud services, AI, and Kubernetes!”. The talk took place on August 1, 2026, during the August edition of Tech Summit in São Paulo, Brazil.

Examples used:
- [**.NET 10 + ASP.NET Core + Oracle + Grafana + Tempo + Loki + Prometheus**](https://github.com/renatogroffe/aspnetcore10-opentelemetry-grafana-tempo-loki-prometheus-oracle-testcontainers_contagemacessos)
- [**Java + Spring Boot + Apache Camel + Grafana + Tempo**](https://github.com/renatogroffe/java-spring-camel_apiconsumobackend)
- [**APISIX + OpenBao (HashiCorp Vault) + Grafana + Prometheus**](https://github.com/renatogroffe/apisix-ai-gateway-microsoftfoundry-vault-otel-grafana-prometheus-dockercompose)

Kubernetes dashboards using Prometheus metrics: **https://github.com/dotdc/grafana-dashboards-kubernetes**
